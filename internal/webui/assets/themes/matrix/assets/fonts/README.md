# Pixelify Sans

The unmodified variable font is bundled for offline UI rendering. Source:
[Google Fonts](https://github.com/google/fonts/tree/main/ofl/pixelifysans).
The accompanying `OFL.txt` contains the font's SIL Open Font License.

The UI uses weight 700. Terminal output retains the application's shared
monospace font stack so code alignment and CJK cell widths stay consistent.
